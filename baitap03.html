Cách đếm thời gian

Không trừ biến đếm mỗi giây, vì setInterval có thể trễ và bị trình duyệt giảm tần suất khi tab chạy nền. Thay vào đó lưu mốc kết thúc endAt = Date.now() + remainingMs, mỗi 250 ms tính lại endAt - Date.now() và chỉ cập nhật DOM khi số giây hiển thị thay đổi. Nhờ vậy đồng hồ không bị lệch dần.

Xử lý interval để tránh memory leak

  • Lưu id của interval vào biến timerId. Hàm start() kiểm tra timerId !== null trước khi tạo mới, nên bấm Bắt đầu nhiều lần không sinh ra nhiều interval chồng nhau (mỗi interval giữ callback và closure trong bộ nhớ và làm đồng hồ chạy nhanh gấp bội).
  • Gọi clearInterval ở mọi điểm dừng: tạm dừng, đặt lại, hết giờ và khi rời trang (pagehide).
  • Các listener chỉ gắn một lần lúc tải trang, không gắn thêm trong mỗi lần tick.

Animation và modal

Khi còn dưới 60 giây, JS thêm class warn; CSS dùng @keyframes chỉ đổi transform nên không gây reflow, và tắt hiệu ứng nếu người dùng bật prefers-reduced-motion. Hộp thoại dùng thẻ <dialog> với showModal(): có sẵn lớp nền, giữ focus bên trong và đóng bằng phím Esc.

Tích hợp với domain và hosting

Hosting tĩnh như GitHub Pages chỉ phát file, toàn bộ việc đếm chạy trên máy người dùng, mà đồng hồ máy có thể sai hoặc bị chỉnh tay. Nếu cần chính xác (ví dụ thi online), phải lấy giờ từ server qua header Date của phản hồi HTTP và tính độ lệch:

const t0 = Date.now();
const res = await fetch(location.href, { method: 'HEAD', cache: 'no-store' });
const serverNow = new Date(res.headers.get('Date')).getTime();
const offset = serverNow - (t0 + Date.now()) / 2;  // độ lệch client so với server
const now = () => Date.now() + offset;             // dùng thay cho Date.now()

Header Date chỉ chính xác đến 1 giây và cần chạy qua http hoặc https, không chạy khi mở file trực tiếp.
